# 🪔 Vighnaharta: Break My Obstacle

A full-stack Ganesh Chaturthi festival endless-runner web application built with **React**, **Vite**, **Tailwind CSS**, **HTML5 Canvas**, and **Supabase** (Database, Anonymous Auth & Real-time Subscriptions).

---

## 🌟 Concept

Players submit real personal obstacles they are facing in life (e.g. *"exam stress"*, *"procrastination"*, *"placement anxiety"*). These get stored in the database. In the game, player controls Lord Ganesha's divine mouse **Mushika**, running through obstacle blocks created from **everyone's submitted real obstacles** scrolling across the screen.

Smashing an obstacle block updates that obstacle's status as `destroyed` in the database, increments the global `total_obstacles_destroyed` counter in real time, and updates the **Community Wall** projection grid for everyone at the event!

## 🚀 Quick Start Instructions

1. **Install Dependencies**:
   ```bash
   npm install
   ```

2. **Run Dev Server**:
   ```bash
   npm run dev
   ```
   Open `http://localhost:3000` in your browser.

> ⚡ **Offline / Demo Mode**: If Supabase environment variables are not yet added to your `.env` file, the app automatically runs in **Mock Demo Mode** using local state and real-time events, so you can test all features immediately!

## 🗄️ Supabase Setup Instructions

Create a `.env` or `.env.local` file in the root directory with your Supabase credentials:

```env
VITE_SUPABASE_URL=https://YOUR_SUPABASE_PROJECT_ID.supabase.co
VITE_SUPABASE_ANON_KEY=YOUR_SUPABASE_ANON_KEY
```

### SQL Database Schema

Run the following SQL queries in your Supabase SQL Editor to create the 3 required tables:

```sql
-- 1. Create obstacles table
CREATE TABLE public.obstacles (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  text TEXT NOT NULL,
  category TEXT NOT NULL DEFAULT 'Other',
  destroyed BOOLEAN NOT NULL DEFAULT false,
  destroyed_by TEXT,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Create scores table
CREATE TABLE public.scores (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  player_name TEXT NOT NULL,
  obstacles_destroyed INT NOT NULL DEFAULT 0,
  modaks_collected INT NOT NULL DEFAULT 0,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Create stats table (Single row counter)
CREATE TABLE public.stats (
  id INT PRIMARY KEY DEFAULT 1,
  total_obstacles_destroyed INT NOT NULL DEFAULT 0
);

-- Insert initial single row into stats
INSERT INTO public.stats (id, total_obstacles_destroyed) 
VALUES (1, 0)
ON CONFLICT (id) DO NOTHING;

-- Enable Realtime for all tables
ALTER PUBLICATION supabase_realtime ADD TABLE public.obstacles;
ALTER PUBLICATION supabase_realtime ADD TABLE public.scores;
ALTER PUBLICATION supabase_realtime ADD TABLE public.stats;

-- Enable Row Level Security (RLS) & Public Policies
ALTER TABLE public.obstacles ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.scores ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.stats ENABLE ROW LEVEL SECURITY;

CREATE POLICY "Allow public read/write on obstacles" ON public.obstacles FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Allow public read/write on scores" ON public.scores FOR ALL USING (true) WITH CHECK (true);
CREATE POLICY "Allow public read/write on stats" ON public.stats FOR ALL USING (true) WITH CHECK (true);
```
